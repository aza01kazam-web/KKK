# For You

This project now serves a single self-contained homepage:

- `index.html` contains the full UI, styling, and client-side behavior
- `app.py` serves `index.html` and local assets such as images

## Files in use

- `app.py`
- `index.html`
- `best-1.png`
- `best-2.png`
- `best-3.jpg`
- `requirements.txt`

## Run locally

1. Install Python 3.
2. Install dependencies with `pip install -r requirements.txt`.
3. Start the app with `python app.py`.
4. Open `http://127.0.0.1:5000/`.
